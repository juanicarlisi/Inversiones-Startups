# apps/

Las apps del holding viven en **repositorios propios**, no acá. Esta carpeta indica dónde está cada una y guarda, de forma temporal,
los prototipos que todavía no tienen repositorio (como Senda en el sprint 0).

| App | Dónde | Proyecto |
|---|---|---|
| **Senda** (Biblia + juegos para jóvenes) | `juanicarlisi/senda-app` (privado) | `oportunidades/proyectos/senda/` |
| **Hub Nocturno** (juego web de red aérea con hub y carga; prototipo v0 del 17-10-2026) | `apps/juegos/aviacion/` (temporal) | `oportunidades/proyectos/P6-juegos.yaml` (JG4) |
| **Andén** (calculadoras logísticas; v0 del 17-10-2026) | `apps/anden/` (temporal) | `oportunidades/proyectos/P2-anden.yaml` |

Cuando el fundador cree los repositorios (por ejemplo `carpincho-games` y `anden`), los prototipos se mueven con su historia y acá
queda solo el enlace.

La copia temporal de `senda-app` que estuvo acá durante el sprint 0 se borró el 05-10-2026, cuando se creó su repositorio (su
historia sigue en el git de este repositorio).
